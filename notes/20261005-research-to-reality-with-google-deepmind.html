연구에서 현실로: DeepMind의 열린 모델

Google DeepMind가 최근 내놓은 API와 열린 모델 Gemma 4를 소개하는 발표다. 핵심은 작은 모델이 브라우저와 폰 안에서, 데이터를 밖으로 보내지 않고, 큰 모델에 가까운 성능을 낸다는 것이다.

원본 영상: Research to Reality with Google DeepMind 발표: Paige Bailey (Google DeepMind)

영어 발표의 자동 자막을 바탕으로 한글로 정리했다. 수치는 모두 발표자가 인용한 것이고 원 출처를 따로 확인하지는 않았다. 자막에서 이름이 뭉개진 곳은 확실한 것만 알려진 이름으로 바로잡았다. mm:ss는 영상 위치다.

영상은 10분 53초에서 끝난다. 발표자가 예고한 컴퓨터 사용 API와 음성 번역 데모는 담겨 있지 않다. 이 노트는 녹화된 앞부분만 다룬다.

발표자는 Google DeepMind 소속이고, 발표 내용은 모두 Google 제품이다. 성능과 비용에 관한 주장은 그 점을 감안해 읽자.

3분 요약
  1. DeepMind는 AI를 책임 있게, 인류에 이롭게 만드는 것을 사명으로 둔다. AlphaFold, MedGemma, 로보틱스, 수학 연구가 그 예다.
  2. 최근 몇 달 사이 컴퓨터 사용 API, 관리형 에이전트, 음성 대 음성 번역 API, Gemini 3.5 Flash가 나왔다.
  3. Gemma 4는 열린 모델 가족이다. 2B, 4B, 12B, 26B(전문가 혼합), 31B(밀집) 다섯 크기이고 Apache 2.0 라이선스다.
  4. 커뮤니티 데모에서 Gemma 4는 브라우저 안에서 WebAssembly로 돌았다. API를 쓰지 않으니 데이터가 밖으로 나가지 않는다.
  5. Google AI Edge Gallery 앱으로 폰에서 이미지 설명, 다국어 음성 받아쓰기, 함수 호출을 무료로 써 볼 수 있다.
  6. 31B와 26B는 열 배 큰 모델보다 좋은 점수를 낸다고 발표자는 말한다. 분산 추론 없이 보통 GPU 한 장으로 돈다.
  7. 12B 이하는 노트북, 2B는 폰에서 돈다. QAT 양자화 체크포인트는 2B 기준 1GB가 안 된다.
01

DeepMind가 모델을 만드는 이유 03:00

발표자 Paige Bailey는 시작하면서 DeepMind의 사명을 먼저 말한다. AI를 책임 있게, 인류에 이롭게 만드는 것이다. 오늘 보여 줄 모델과 도구는 모두 그 사명 아래의 과학 연구에 실제로 쓰이고 있다고 한다.

  • AlphaFold: 단백질 구조를 예측하는 모델
  • MedGemma: 의료용으로 만든 열린 모델 open model
  • 로보틱스와 과학: AI로 수학을 풀고, 최전선 연구를 빠르게 하는 일

AI로 과학을 하는 사람이 있다면 발표 뒤에 따로 물어 달라고 했다. 발표의 톤은 "제품 소개"보다 "이걸로 좋은 일을 더 빨리 하자"에 가깝다.

02

최근 몇 달의 출시물 03:50

발표자는 Google이 매주 새 모델과 기능을 내놓는 것처럼 느껴진다고 말한다. 그중 발표에서 짚은 것은 네 가지다.

출시물무엇인가
컴퓨터 사용 API computer use API모델이 화면을 보고 컴퓨터를 직접 조작하게 하는 API. 발표 뒤쪽에서 다룰 예정이었다
관리형 에이전트 managed agents큰 작업을 말로 설명하면 여러 에이전트가 Linux 작업 환경 같은 격리된 공간에서 수행한다. 스킬과 의존성을 중간에 끌어올 수 있다
음성 대 음성 번역 API speech-to-speech translation API말을 다른 언어의 말로 바로 바꾼다. 데모 예정이었으나 녹화에 없다
Gemini 3.5 FlashI/O에서 공개한 최전선 모델 frontier model

발표자가 강조한 것은 Google이 최전선 모델만 만드는 게 아니라 열린 모델에도 꾸준히 힘을 쏟는다는 점이다. 그 열린 모델이 Gemma다.

03

Gemma 4 모델 가족 04:50

Gemma 4는 Google의 열린 모델 가족 중 가장 최신이다. 크기가 다섯 가지다. 가장 큰 두 모델은 구조가 다르다. 26B는 전문가 혼합 mixture of experts 방식이고, 31B는 밀집 dense 모델이다.

Apache 2.0 라이선스 내려받아 회사 안에서 쓰고, 미세 조정 fine-tune하고, 원하는 대로 확장할 수 있다. 상업적 이용에 제한이 거의 없는 라이선스다.

발표자는 "슬라이드를 싫어한다"며 데모 위주로 진행하겠다고 했다. 그래서 모델 세부 수치는 발표에 거의 나오지 않는다.

04

브라우저 안에서 도는 Gemma 05:50

첫 데모는 커뮤니티의 누군가가 만든 웹 페이지다. Gemma 4를 WebAssembly로 브라우저 안에 그대로 올린다. 격리된 환경 sandboxed에서 모델이 완전히 로컬로 돈다.

발표자는 이 데모가 Gemma 4와 "Fable 5"로 만들어졌다고 말했다. 자막 기준이며 맥락은 확인할 수 없다.

데모 입력 06:20

해리 포터 시리즈 전권을 재미와 긴장감 기준으로 이모지 표로 비교하고, 어떤 책부터 읽을지 추천해 달라. 팬 소설 "해리 포터와 합리성의 방법" Harry Potter and the Methods of Rationality도 넣어 달라.

결과 07:00

거의 즉시 답이 나왔다. 죽음의 성물, 혼혈 왕자, 불사조 기사단, 불의 잔 순서로 표가 만들어졌다. 발표자는 순위에 동의하지는 않지만 흥미로운 비교라고 했다.

왜 이 데모가 중요한가 07:20 API를 호출하지 않는다. 데이터가 내 기기를 떠나지 않는다. 쓰인 것은 transformers.js와 Gemma 4 모델뿐이다. 개인 정보가 민감한 작업을 서버 없이 처리할 수 있다는 뜻이다.

이 데모가 그렇게 빨랐던 이유는 뒤에 나온다. 양자화한 QAT 체크포인트를 썼기 때문이다. 7절에서 다시 본다.

05

폰에서 써 보는 AI Edge Gallery 07:40

Google AI Edge Gallery는 Android와 iOS용 앱이다. 기기 안에 설치한 모델만으로 무엇이 되는지 직접 만져 볼 수 있다. 무료다.

  • 이미지 설명: 사진을 찍으면 내용을 말로 풀어 준다
  • 음성 받아쓰기: 여러 언어를 자동으로 글로 옮긴다. 발표자는 Gemma가 140개 넘는 언어를 지원한다고 기억했다
  • 함수 호출 function calling: 모델이 기기 안의 기능을 직접 부른다
  • 스킬 모음: 게임 만들기, 하이쿠 쓰기, 날씨 묻기, 캘린더에 일정 잡기
CPU가 아니라 가속기로 08:40 기기에 있는 AI 가속기로 추론을 돌리는 옵션이 있다. CPU로 떨어지지 않으니 훨씬 빠르다. Pixel 10 같은 상위 기기라면 지금 바로 Gemma를 로컬로 쓸 수 있다고 발표자는 말한다.
06

작은 크기, 큰 성능 09:00

발표자는 31B와 26B 모델의 성능 대 크기 그래프를 보여 줬다. 두 모델은 시장의 다른 모델에 비해 꽤 작은데도, 자기보다 열 배 큰 모델보다 좋은 점수를 낸다고 한다. 구체적 벤치마크 수치는 발표에 나오지 않았다.

이 비교는 발표자가 Google의 그래프를 보고 말한 것이다. 어떤 벤치마크와 어떤 모델을 비교했는지는 자막에 없다.

왜 비용이 줄어드나

  • 모델이 작으면 분산 추론 distributed inference이 필요 없다. 여러 GPU에 모델을 쪼개 올리는 복잡한 일을 안 해도 된다.
  • GPU를 덜 차지한다. 데이터 센터급 장비 대신 보통 GPU 한 장에서 잘 돌도록 만들었다.
07

어디서 돌릴 수 있나 10:00

발표자가 말한 크기별 실행 환경을 정리하면 이렇다.

크기돌릴 수 있는 곳
2B폰에 넉넉히 들어간다
12B 이하노트북에서 로컬로 돈다
일부 변형Jetson Nano(추정) 같은 소형 보드에서도 돈다
26B · 31B보통 GPU 한 장

자막에는 "Jets and Nanos"로 적혀 있다. NVIDIA의 소형 보드 Jetson Nano로 추정한다.

양자화 체크포인트 10:10

Gemma 4는 양자화 quantized 버전도 함께 나왔다. 양자화는 모델 숫자의 정밀도를 낮춰 크기와 메모리를 줄이는 기법이다. 특히 QAT 체크포인트는 학습 단계에서부터 양자화를 고려해 만들어 정확도 손실이 적다.

4절의 데모가 빨랐던 이유 브라우저 데모는 이 QAT 체크포인트를 썼다. 2B 버전은 1GB가 안 된다. 그래서 브라우저에 내려받아 바로 돌릴 수 있었다.

영상은 이 설명 직후에 끝난다. 뒤에 이어졌을 데모와 질의응답은 녹화에 없다.

핵심 정리

  1. DeepMind의 사명은 책임 있는 AI, 인류에 이로운 AI다. AlphaFold, MedGemma, 로보틱스가 그 예다.
  2. 최근 출시물은 컴퓨터 사용 API, 관리형 에이전트, 음성 대 음성 번역 API, Gemini 3.5 Flash다.
  3. Google은 최전선 모델과 열린 모델을 같이 만든다. 열린 모델이 Gemma다.
  4. Gemma 4는 2B, 4B, 12B, 26B, 31B 다섯 크기다. 26B는 전문가 혼합, 31B는 밀집 모델이다.
  5. 라이선스는 Apache 2.0이다. 회사에서 쓰고, 미세 조정하고, 확장할 수 있다.
  6. Gemma 4는 브라우저 안에서 WebAssembly와 transformers.js로 돈다. API 호출이 없고 데이터가 밖으로 나가지 않는다.
  7. Google AI Edge Gallery로 폰에서 이미지 설명, 다국어 받아쓰기, 함수 호출을 무료로 써 볼 수 있다.
  8. 상위 폰은 CPU 대신 AI 가속기로 추론을 돌린다.
  9. 31B와 26B는 열 배 큰 모델보다 좋다고 발표자는 말한다. 분산 추론 없이 보통 GPU 한 장이면 된다.
  10. 12B 이하는 노트북, 2B는 폰이다. QAT 양자화 체크포인트는 2B 기준 1GB 미만이다.

AI를 책임 있게, 인류에 이롭게 만드는 것. AlphaFold, MedGemma, 로보틱스, AI 수학 연구가 그 사명 아래에서 진행된다.

2B, 4B, 12B, 26B, 31B. 12B는 발표 직전에 공개됐다.

26B는 전문가 혼합(mixture of experts), 31B는 밀집(dense) 모델이다.

API를 호출하지 않는다. WebAssembly와 transformers.js로 모델이 브라우저 안에서 완전히 로컬로 돈다.

이미지 설명, 여러 언어 음성 받아쓰기, 기기 안에서 함수 호출. 게임 만들기, 하이쿠, 날씨, 캘린더 일정 같은 스킬도 있다.

분산 추론이 필요 없고, GPU를 덜 차지한다. 보통 GPU 한 장에서 돌도록 만들었다.
Q10브라우저 데모가 그렇게 빨랐던 이유는?
QAT 양자화 체크포인트를 썼다. 2B 버전은 1GB가 안 돼서 브라우저에 내려받아 바로 돌릴 수 있다.
Q11크기별로 어디서 돌릴 수 있나?
2B는 폰, 12B 이하는 노트북, 일부 변형은 Jetson Nano(추정) 같은 소형 보드, 26B와 31B는 보통 GPU 한 장.

용어 정리

용어뜻
열린 모델Open model. 가중치를 공개해 누구나 내려받아 돌리고 고칠 수 있는 모델
최전선 모델Frontier model. 그 시점에서 가장 성능이 높은 축에 드는 모델
파라미터모델 안의 학습된 숫자. 2B는 20억 개라는 뜻이다. 많을수록 크고 무겁다
전문가 혼합Mixture of experts. 모델을 여러 전문가 조각으로 나누고 입력마다 일부만 쓰는 구조. 전체 크기에 비해 계산이 적다
밀집 모델Dense model. 모든 파라미터를 매번 다 쓰는 보통 구조
Apache 2.0상업 이용, 수정, 재배포를 폭넓게 허용하는 오픈소스 라이선스
미세 조정Fine-tune. 이미 학습된 모델을 내 데이터로 조금 더 학습시키는 것
WebAssembly브라우저 안에서 네이티브에 가까운 속도로 코드를 돌리는 기술
transformers.js브라우저와 JavaScript 환경에서 AI 모델을 돌리는 라이브러리
온디바이스On-device. 서버에 보내지 않고 폰이나 노트북 안에서 처리하는 것
함수 호출Function calling. 모델이 답 대신 "이 함수를 이 인자로 불러라"를 내놓아 실제 기능을 실행하게 하는 방식
